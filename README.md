## Stack

- **Kubernetes**: workload hosting (cluster access pending)
- **Dash0**: OpenTelemetry-native observability (traces, metrics, logs)

## Getting started

```bash
git clone https://github.com/DillanMena/wemakedevs-brogrammers.git
cd wemakedevs-brogrammers
cp .env.example .env   # fill in Dash0 / Elastic credentials — never commit .env
```

### Prerequisites

- Docker
- kubectl
- Helm 3+
